# Python Backend Practice Projects

A collection of hands-on Python projects built to strengthen my Python programming and backend development skills.

## Projects

### 1. Document Analyzer with Logging

A Python program that reads a text file, analyzes its contents, and records application events and errors using Python logging.

**Features**
- Read files using Python file handling
- Use pathlib to work with file paths
- Count total lines, words, and characters
- Handle missing files using FileNotFoundError
- Handle empty documents with a custom EmptyDocumentError
- Record application events and errors in a log file

**Technologies:** Python, pathlib, File Handling, Exception Handling, Logging

### 2. Async API Data Aggregator

A Python program that fetches data from APIs asynchronously and analyzes posts associated with a selected user.

**Features**
- Fetch API data using HTTPX
- Use async/await for asynchronous programming
- Run multiple API requests concurrently using asyncio.gather()
- Handle API request failures
- Find a user by ID and count their posts
- Handle cases where the requested user is not found

**Technologies:** Python, HTTPX, asyncio, REST APIs, Exception Handling

## What I Practiced

- Custom exceptions and error handling
- Logging application events
- HTTP requests and JSON responses
- Asynchronous programming and concurrent requests
- Working with real API responses
